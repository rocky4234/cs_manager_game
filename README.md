# CS电竞经理游戏 — 项目文档

**版本**：0.1  
**日期**：2026年10月8日  
**状态**：当前阶段目标确认  
**用途**：同步项目方向与近期开发计划

---

## 一、项目定位

本项目旨在开发一款以比赛为核心的CS电竞经理模拟游戏。玩家将扮演一人全包的战队经理、教练与老板，从零组建战队，通过转会市场与青训体系获取选手，在实时比赛中设置战术、关键时刻微调走位，带领队伍从底层赛事逐步晋级至Major殿堂。游戏采用多赛季生涯模式，上架Steam平台。

---

## 二、核心玩法概述

- **玩家角色**：一人全包。负责选手招募、战术制定、比赛指挥、俱乐部经营等全部事务。
- **比赛机制**：实时进行，不可暂停，不可调速。玩家在比赛中可切换战术卡、下达移动指令，但射击、道具、交火均由AI自动处理。
- **设计原则**：比赛是游戏的核心。其他所有系统（转会、抽卡、成长、财务、事件）均为比赛提供输入与输出。玩家的所有决策最终需在比赛中接受检验。
- **战术卡与移动指令**：战术卡为主要指挥手段，通过俱乐部任务树解锁；移动指令为应急手段，用于关键时刻调整单个选手位置。

## 三、当前阶段目标：1v1原型验证

### 3.1 目标描述

使用raylib图形库，构建一个可运行的1v1 AI对战原型。两名AI选手在地图上互相交战，直至一方被击败。

### 3.2 需验证的核心问题

1. AI能否做出合理决策（追击、开火、撤退）？
2. 交火节奏是否符合预期（几秒内分出胜负）？
3. 枪法数值是否平衡（例如拿AWP是否过强，其他枪则过弱）？
4. 现有代码结构能否扩展至5v5？

### 3.3 完成标准

原型可持续运行十分钟以上，且能明确回答上述四个问题。

### 3.4 实现内容

- raylib窗口创建，2D俯视图渲染，地图以矩形色块表示。
- 两个实体（蓝方与红方），各含生命值、枪法、移动速度、武器等属性。
- 枪法包括以下属性：命中率（根据武器而异），压枪准确度（随着时间推移命中率降低），爆头率（每发射击单独进行判定一次）
- AI决策逻辑：发现敌人时开火，否则考虑主动寻找敌人信息或架点。
- 交火判定：命中率决定，伤害由武器伤害与护甲穿透计算。
- 多种武器：以counter-strike中的武器内容为准。
- 固定时间步长模拟，AI每100毫秒决策一次。

### 3.5 当前阶段范围界定

以下系统在本阶段不予讨论、不予设计、不予编码：

- 转会市场、抽卡系统、经济系统
- Buff树、国策树、多赛季生涯
- 士气系统、地图池熟练度
- 事件系统、教练组、多结局
- 文字解说UI、战术卡系统、创意工坊
- 美术资源、音效、新手引导

上述系统将在1v1原型验证通过后，按开发优先级逐步引入。

## 四、后续开发路线

1v1原型跑通后，按以下顺序逐步扩展，每次仅增加一个变量：

1v2 → 2v2 → 5v5 → 完整回合 → 多回合比赛 → 完整赛事 → 赛季系统

每一步均需验证通过后，方可进入下一阶段。
